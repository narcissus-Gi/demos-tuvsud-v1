# 生产统计异常判断规则

> 本文件定义生产统计数据的异常说明与判断逻辑。
> 所有异常判断必须依据本文件，不得自行设定阈值或凭经验判断。

## 规则

occurred_at 为该异常发生的日期时间，必须是ISO 8601 标准的日期时间格式，如果不是，则在报告总结里记录下对应的ID，并说明“ occurred_at 格式出错”。

下表为 alarm_code 编号所对应的实际异常。

| 编号 | 说明 |
| :--- | :--- |
| E401 | 温度过高，超过上限80°C |
| E402 | 停止生产 |
| E405 | 未知问题 |
| E410 | 通信中断 |
